# Conversations and memory

## Conversation modes

Ordinary chat, branching Ideascapes and group modes share canonical messages,
participants and artifacts. Autonomous discussion owns ordered participant turns
and existing stop conditions. Collaboration owns causal speaker waves and cannot
simultaneously share progression ownership with Autonomous discussion.

Convex resolves current Persona defaults for new logical turns and retains the
captured effective configuration for active turns/replay. Published messages retain
attribution when a Persona or device changes. See [Persona routes](../runtime/personas.md).

## Shared memory

Memory extraction and reconciliation run through the shared post-generation owners.
Preferences, source admission, pending approval, pins, scopes and explicit deletion
remain authoritative. Shared memory storage and retrieval do not fork by cloud,
Codex or Pi origin. Query embeddings and hydrated memory context use canonical
owned caches. Unknown cost or unavailable context is not invented.

Structured helper judgments can reinforce or supersede admitted facts with
provenance; inferred contradiction does not authorize hard deletion. Explicit
forgetting uses the existing owned deletion and relationship/embedding cleanup.
See [helper contracts](../development/helper-evaluation.md) and
[context assembly](context-assembly.md).
